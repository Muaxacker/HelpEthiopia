🚀 Quick Start Guide

📋 What is HelpEthiopia?

HelpEthiopia is a smart donation platform that connects generous donors with verified recipients across Ethiopia. Built with pure HTML, CSS, and JavaScript, it requires no backend server and stores all data locally in your browser.

✨ Key Features

🎁

Post Donations

Share items you want to donate with photos and details

📍

Make Requests

Request specific items with urgency levels

🗺️

Interactive Map

See all donations and requests on a visual map

🔍

Search & Filter

Find exactly what you need with powerful filters

💾

Data Persistence

All data saved locally in your browser

📱

Responsive Design

Works perfectly on all devices

🎯 Getting Started in 3 Steps

1

Create Your Account

Click the "Sign Up" button in the navigation bar. Fill in your details and select your role:

  • • Donor - If you want to donate items
  • • Recipient - If you need assistance
  • • NGO/Admin - If you represent an organization

Sign Up Now →

2

Post or Browse

If you're a donor:

  • • Click "Post a Donation"
  • • Fill in item details (name, category, condition, quantity)
  • • Upload a photo (optional but recommended)
  • • Add a description and submit

If you're a recipient:

  • • Click "Make a Request"
  • • Describe what you need
  • • Set urgency level and location
  • • Provide contact information
3

Connect & Help

Browse available items, use the map to find nearby donations/requests, and connect with others to make a difference!

🔧 Technical Information

No Installation Required! Just open index.html in your browser.

Technologies Used:

  • • HTML5 - Semantic markup
  • • CSS3 - Custom styles (no Bootstrap or Tailwind)
  • • Vanilla JavaScript - No frameworks or libraries
  • • LocalStorage - Data persistence
  • • SessionStorage - User sessions

File Structure:

├── items.html              # Browse items
├── donate.html             # Post donation

💡 Tips & Best Practices

  • • Upload clear photos of items to increase trust
  • • Be specific in descriptions (size, condition, expiry dates)
  • • Set accurate locations for easier matching
  • • Use urgency levels appropriately for requests
  • • Check the map to find nearby donations/requests
  • • Update your dashboard regularly

❓ Frequently Asked Questions

Is my data safe?

All data is stored locally in your browser using localStorage. No data is sent to external servers.

Can I use this without internet?

Once loaded, the app works offline. However, you need internet to initially load the page and external resources (fonts, icons).

How do I delete my data?

Clear your browser's localStorage or use the delete buttons in your dashboard.

Can I use this on mobile?

Yes! The platform is fully responsive and works on all devices.

Is this production-ready?

This is a demonstration project. For production use, you should add server-side authentication, database storage, and proper security measures.
